## 📌 About The Project

**Dev Stack** is a modern **Tech Stack Builder & Technology Showcase Web Application** for exploring different technologies and creating a personalized tech stack.

The project is built with **React, TypeScript, Tailwind CSS and DaisyUI**, with a clean, modern and responsive user interface.

## 📚 React Questions & Answers

<details>
<summary><strong>1. What is JSX, and why is it used in React?</strong></summary>

<br>

<p>
JSX is a syntax that allows us to write HTML-like code inside JavaScript or TypeScript.
It makes React UI code easier to read, write, and understand.
</p>

</details>

<br>

<details>
<summary><strong>2. What is the difference between props and state?</strong></summary>

<br>

<p>
<strong>Props</strong> are used to pass data from a parent component to a child component.
Props are read-only and cannot be directly changed by the child component.
</p>

<p>
<strong>State</strong> is data managed inside a component. When the state changes,
React re-renders the component and updates the UI.
</p>

</details>

<br>

<details>
<summary><strong>3. What does the <code>useState</code> hook do, and where did you use it in this project?</strong></summary>

<br>

<p>
The <code>useState</code> hook is used to create and manage state inside a React component.
When the state changes, React updates the UI.
</p>

<p>
In this project, I used <code>useState</code> to manage the technologies selected by the
user for their personalized tech stack.
</p>

</details>

<br>

<details>
<summary><strong>4. What does the <code>useEffect</code> hook do, and why did you need it to load the JSON data?</strong></summary>

<br>

<p>
The <code>useEffect</code> hook is used to perform side effects in a React component,
such as fetching data or interacting with external resources.
</p>

<p>
I used <code>useEffect</code> to load the technology data from the JSON file when the
application starts.
</p>

</details>

<br>

<details>
<summary><strong>5. Why does every item in a <code>.map()</code> list need a unique <code>key</code> prop?</strong></summary>

<br>

<p>
React uses the <code>key</code> prop to uniquely identify each item in a list.
A unique key helps React determine which items have changed, been added, or removed,
allowing it to update the UI efficiently.
</p>

</details>

<br>

<details>
<summary><strong>6. What is conditional rendering? Show one place you used it.</strong></summary>

<br>

<p>
Conditional rendering means displaying different UI elements based on a specific condition.
</p>

<p>
In this project, I used conditional rendering to display a message when no technology
has been selected by the user.
</p>

</details>
